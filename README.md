# melhorando-habilidades-em-python

Repositório de programas em Python para melhorar meus conhecimentos

# Mapa do Curso

# Fase 1:
Fácil — Sintaxe Básica, Variáveis, Operadores, Controle de Fluxo (if/else, loops) e Funções Simples.

# Fase 2: 
Médio — Estruturas de Dados (Listas, Tuplas, Dicionários, Conjuntos), Manipulação de Arquivos e Programação Orientada a Objetos (POO).

# Fase 3: 
Avançado — Decoradores, Gerenciadores de Contexto, Concorrência/Assincronismo e Otimização de Códigos (PEP 8 / Clean Code).
